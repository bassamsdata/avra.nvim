01 / GET STARTED

Installation

Install Neovim 0.13+, Git, curl, tar/gzip, unzip, a C compiler and make, Node.js/npm, Rust/Cargo, Tree-sitter CLI 0.26.1+, Python 3.10+ with pip/venv, uv, ripgrep, and fd. Internet access is needed for the first run. A Nerd Font is optional.

ONE COMMAND · MACOS / LINUX
mkdir -p "${XDG_CONFIG_HOME:-$HOME/.config}" && git clone https://github.com/bassamsdata/avra.nvim.git "${XDG_CONFIG_HOME:-$HOME/.config}/nvim.avra" && NVIM_APPNAME=nvim.avra nvim

The folder must not already exist. Keep Neovim open while plugins, parsers, and Mason tools install. Future launches use NVIM_APPNAME=nvim.avra nvim. To retry a failed download, restart and check :messages, :Mason, or :checkhealth.

03 / DAILY USE

What to reach for

Find

Space ff finds files, Space fb buffers, and Space / text through Snacks. Space fk browses mappings.

Understand

Space ss and Space sw open Namu symbols. Move with Ctrl-n / Ctrl-p; the source previews automatically. Enter accepts.

Fix

Space d opens diagnostic details; ]e / [e jump errors. Space si opens file diagnostics in Namu. gra offers code actions.

Move

gd jumps to definition, Ctrl-o returns, grr finds references, and Alt-h/j/k/l switches windows.

Mask secrets

Assignment values in .env, .env.*, *.env, .npmrc, .pypirc, and ~/.aws/credentials are hidden with one * per character, including multiline values. Use Space up or :SecretsToggle to reveal or hide the current file.

The native module loads only for matching files. Masking affects the buffer display; saved text, clipboard contents, search results, and previews still contain the real values. Add assignment-based file patterns in plugin/_load.lua; JSON and YAML are not parsed.

04 / TOOLING

Language support

First launch installs baseline Tree-sitter parsers and Mason tools. Lua gets LuaLS and StyLua. Python uses Pyrefly for hover, completion, navigation and rename; ty for type diagnostics; and Ruff for linting, formatting and code actions. Their overlapping features are disabled in the configuration. Application packages belong in your project’s own environment, not the private Neovim provider.

Other language servers in the configuration are optional and require their own executables. Molten notebook use also needs a suitable Jupyter kernel and any project graphics dependencies. See the Python setup review for the exact split.
